# T11 — Accessibilité : passage sur les écrans récents

Lis d'abord `docs/agents/COORDINATION.md`.

## But
Un passage lecteur d'écran / zones tactiles / contraste sur ce qui a été ajouté
récemment : draft (bannissements, conseils, score), historique, page de détail,
filtres de rôle, barre de navigation, boîtes de dialogue d'import. Référentiel :
RGAA (contraste ≥ 4,5:1 pour le texte, zone tactile ≥ 44 px, nom accessible
pour tout contrôle, état annoncé).

## À faire
1. **Audit** → `docs/agents/reports/a11y-audit.md` : tableau
   `écran / élément / problème / correctif / fait ?`. Parcours au moins :
   `lib/draft/**` (page, widgets, historique, détail, import), 
   `lib/shared/widgets/**` (`app_filter_chip`, `champion_picker_sheet`,
   `paste_code_dialog`, `data_source_note`, `counter_tile`, `lane_filter_bar`),
   `lib/main_navigation/**`, `lib/theme/widgets/theme_mode_sheet`.
2. **Corrige** ce qui relève de ces dossiers. Pistes déjà connues :
   - `AppFilterChip` n'a pas de `Semantics(button: true, selected: …)` : l'état
     sélectionné n'est annoncé à personne ; sa hauteur (32 px dans
     `LaneFilterBar` et le sélecteur de rôle) est sous les 44 px de zone
     tactile : agrandis la **zone tactile** (padding/`minimumSize`) sans
     changer l'aspect visuel quand c'est possible.
   - Titres de sections des bilans (`POURQUOI`, `BANNISSEMENTS`, `CE QUI VA
     BIEN`, `À AMÉLIORER`, `SUGGESTIONS`…) : `Semantics(header: true)`.
   - Les cases de `DraftSlot`/`BanRow`/`SuggestionCard` : libellé complet et
     action annoncée ; images purement décoratives exclues de l'arbre
     sémantique.
   - Contrôles par icône seule : tooltip **et** libellé.
   - Contraste : vérifie `AppColors.textMuted` sur `surface` et `background` dans
     les **deux** palettes (`AppPalette.dark/light`) avec un petit test de
     contraste (calcul de luminance WCAG) ; si une paire est sous 4,5:1, ajuste
     la **palette** dans `lib/theme/app_colors.dart` (c'est le seul fichier de
     couleur) et dis-le au journal : l'architecte validera visuellement.
   - Les `SnackBar`/messages d'état importants sont annoncés (`liveRegion`).
3. **Tests** : `test/shared/widgets/app_filter_chip_test.dart` (sémantique,
   zone tactile ≥ 44 px), `test/theme/contrast_test.dart`, et un test de
   sémantique par widget corrigé (utilise `tester.ensureSemantics()` et
   `isSemantics`/`containsSemantics` — pas de `pumpAndSettle`).

## Fichiers qui t'appartiennent
`lib/shared/widgets/**`, `lib/draft/**` (tout : T9a/T9b/T16 ont fini),
`lib/main_navigation/**`, `lib/theme/**`, leurs tests, le rapport. **Pas** :
`counters_page`, `strengths_page`, `builds_page`, `team_page`, `build_store`
(T14 y travaille).

## Définition de « fini »
Rapport écrit, correctifs testés, analyse propre sur tes dossiers, message au
journal avec la liste des changements **visibles** (que l'architecte
vérifiera dans le navigateur).
