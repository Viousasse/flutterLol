# T5 — Session « à deux » : noms mémorisés et score de la soirée

Lis d'abord `docs/agents/COORDINATION.md` (surtout §8, contrat T5 → T9b).

## But
En draft à deux, les noms des joueurs doivent survivre entre deux parties (et
au redémarrage), et un score cumulé « Léa 3 – Tom 2 » doit être tenu. T9b
branchera tout ça dans la page ; toi, tu fournis le store et un widget.

## À lire
`lib/draft/services/draft_history_store.dart` (modèle de store statique avec
`ValueNotifier`, `ensureLoaded`, file d'écriture, `reset()` pour les tests),
`lib/draft/models/draft_report.dart` (`DraftPlayers`, `DraftWinner`),
`lib/draft/models/draft_mode.dart` (`friendPlayers` = valeurs par défaut),
`lib/draft/widgets/player_name_dialog/player_name_dialog.dart` (règles de nom :
`validatePlayerName`, `playerNameMaxLength`).

## À faire
1. `lib/draft/services/friend_session_store.dart` selon le **contrat §8** :
   - clé `shared_preferences` : `friend_session` (un JSON) ; lecture tolérante
     (entrée illisible → valeurs par défaut, sans planter) ;
   - noms par défaut : ceux de `friendPlayers` ;
   - `rename` applique `validatePlayerName` : un nom vide ou identique à celui
     de l'autre joueur est refusé **sans exception** (renvoie sans rien changer) ;
     le nom est `trim()` ;
   - `recordResult(DraftWinner)` : bleu → `blueWins++`, rouge → `redWins++`,
     égalité → `ties++` ;
   - **renommer un joueur ne remet pas le score à zéro** (c'est la même soirée) ;
   - `resetScore()` remet les trois compteurs à 0 en gardant les noms ;
   - écritures sérialisées comme dans `DraftHistoryStore`.
2. `lib/draft/widgets/friend_score_bar/friend_score_bar.dart` :
   `FriendScoreBar({required FriendSession session, required VoidCallback onReset})`.
   Affiche « Léa 3 – 2 Tom », « 1 égalité » si > 0, un bouton « Remettre le score
   à zéro » (tooltip, ≥ 44 px de zone tactile), un libellé sémantique complet
   (« Score de la soirée : Léa 3, Tom 2, 1 égalité »). Couleurs
   `AppColors`/`AppTheme` uniquement. Désactive le bouton si le score est déjà
   à zéro.
3. Tests : `test/draft/friend_session_store_test.dart` (par défaut, persistance
   d'un cycle écrire/relire avec `SharedPreferences.setMockInitialValues`, refus
   des noms invalides, score, reset, entrée corrompue) et
   `test/draft/friend_score_bar_test.dart` (affichage, égalité masquée à 0,
   bouton, sémantique).

## Fichiers qui t'appartiennent
Les quatre fichiers ci-dessus uniquement. **Ne modifie pas** `draft_page.dart`.
