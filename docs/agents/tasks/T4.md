# T4 — Conseiller de draft (`DraftAdvisor`)

Lis d'abord `docs/agents/COORDINATION.md` (surtout §8, contrat T4 → T9b).

## But
Pendant la draft, à son tour de choisir, proposer **3 champions** avec la
**raison** de chacun. C'est de la logique pure (aucun écran) : T9b l'intégrera.

## À lire
`lib/draft/services/draft_bot.dart` (poids `counterWeight`, `winRateWeight`,
`needBonus`, `_needBonus`, `_isFrontliner`), `lib/draft/models/draft_state.dart`,
`lib/matchups/services/matchup_service.dart` (`overallFor`, `headToHead`),
`lib/matchups/services/lane_profile.dart`, `lib/team/constants/team_roles.dart`,
`lib/draft/services/draft_evaluator.dart` (pour rester cohérent avec le bilan).

## À faire
1. **Rends réutilisable** la logique de score du bot : dans
   `draft_bot.dart` (que tu es seul à modifier), expose en statique ce dont le
   conseiller a besoin (`needBonusFor`, `isFrontliner`…). Ne change pas le
   comportement du bot : les tests `test/draft/draft_bot_test.dart` doivent
   continuer à passer sans modification.
2. Crée `lib/draft/services/draft_advisor.dart` selon le **contrat §8**
   (`DraftSuggestion`, `DraftAdvisor.suggest`). Règles :
   - Renvoie `[]` pendant la phase de bannissements (`state.isBanPhase`), si la
     draft est finie, ou s'il n'y a pas de rôle libre pour `side`.
   - Candidats : champions de `pool` pas dans `state.unavailableIds`, pour chaque
     **rôle libre** du camp, avec `LaneProfile.fits` (repli : tous les libres si
     aucun ne convient au rôle).
   - Score **déterministe** (aucun hasard) : duel contre l'adversaire déjà placé
     dans ce rôle (`headToHead`), taux de victoire global fiable
     (`OverallRecord.isReliable`), bonus de manque de l'équipe.
   - Une suggestion par champion (son meilleur rôle), triées par score
     décroissant, `count` au maximum, **deux suggestions ne se répètent pas**.
   - `reasons` : 1 à 3 phrases courtes en français, vraies et chiffrées, par
     exemple « Gagne 57 % contre Zed au milieu (42 parties). », « 55 % de
     victoires en Master+. », « Comble le manque de dégâts magiques de votre
     équipe. », « Apporte une première ligne qui vous manque. ». Jamais de
     phrase si la donnée n'est pas fiable (≥ `MatchupService.minGames` parties
     pour un duel, `OverallRecord.isReliable` pour le global). Si aucune raison
     chiffrée n'existe, une phrase honnête : « Se joue régulièrement à ce poste. ».
3. Tests `test/draft/draft_advisor_test.dart` : vide en bannissements / draft
   finie ; déterministe (deux appels identiques) ; privilégie le contre de
   l'adversaire de voie ; ne propose pas un champion banni ou pris ; deux
   suggestions pour des champions différents ; raisons absentes quand les
   données manquent ; raison « comble le manque » quand l'équipe n'a aucun
   dégât magique ; `count` respecté.
