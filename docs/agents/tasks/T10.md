# T10 — Historique : drafts « avec aide », page de détail

Lis d'abord `docs/agents/COORDINATION.md` (surtout §5 verrous et §8 contrats).

## But
1. Une draft jouée **avec les conseils** (T9b) ne se compare pas à une draft
   jouée seul : il faut la marquer et ne pas la compter dans le taux de victoire.
2. Une **page de détail** pour revoir une draft de l'historique, la partager et
   la rejouer.

## À lire
`lib/draft/models/draft_record.dart`, `lib/draft/services/draft_history_stats.dart`,
`lib/draft/draft_history_page.dart`,
`lib/draft/widgets/draft_history_tile/draft_history_tile.dart`,
`lib/draft/widgets/draft_stats_card/draft_stats_card.dart`,
`lib/draft/widgets/ban_row/ban_row.dart`, `lib/draft/widgets/draft_slot/draft_slot.dart`,
`lib/draft/services/draft_share_text.dart` (à ne **pas** modifier : T7),
`test/draft/draft_history_test.dart`, `test/draft/draft_history_widgets_test.dart`.

## À faire
1. **`DraftRecord.assisted`** (contrat §8) : `final bool assisted` (défaut
   `false`) dans le constructeur, `DraftRecord.from(... , bool assisted = false)`,
   `toJson`/`tryFromJson` (`'assisted'`, absent = `false`, donc **les anciennes
   drafts déjà enregistrées se relisent**). Écris au journal dès que c'est fait
   (T7 et T9b l'attendent).
2. **Statistiques** (`DraftHistoryStats`) : le taux de victoire contre le site
   **exclut** les drafts `assisted` ; ajoute `assistedCount` (nombre de drafts
   jouées avec aide, tous modes). Les champions les plus choisis comptent
   toutes les drafts. `DraftStatsCard` affiche « dont N avec aide (non comptées
   dans le taux) » quand `assistedCount > 0`.
3. **Tuile d'historique** : étiquette « avec aide » quand `assisted` ; la tuile
   entière devient **touchable** (`onTap`) et ouvre la page de détail ; garde les
   boutons partager/supprimer. Libellé sémantique unique pour la tuile
   (joueurs, vainqueur, date).
4. **`lib/draft/draft_record_page.dart`** : page de détail d'une `DraftRecord`
   — en-tête (joueurs, date, vainqueur, scores), les deux équipes en lecture
   seule (réutilise `DraftSlot` sans `onTap`, les bans avec `BanRow` sans
   `onTap`, images via un dictionnaire id → URL comme dans `DraftHistoryPage`),
   le verdict, un bouton « Copier le résumé » (`DraftShareText.of` +
   `copyToClipboard`), un bouton « Rejouer avec les mêmes bannissements » qui
   ouvre `DraftPage(replayOf: record)` (**paramètre fourni par T9a** : vérifie
   le journal ; si T9a n'a pas fini, termine le reste et reviens à ce bouton en
   dernier ; en attendant, ne casse pas la compilation de ta part en laissant du
   code qui ne compile pas — écris le bouton seulement quand le paramètre existe).
5. Tests : mets à jour/ajoute dans `test/draft/draft_history_test.dart` (blocs
   `DraftRecord` et `DraftHistoryStats` **seulement**, T7 a le bloc
   `DraftShareText`), `test/draft/draft_history_widgets_test.dart` et un nouveau
   `test/draft/draft_record_page_test.dart`.
