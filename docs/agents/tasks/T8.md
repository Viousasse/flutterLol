# T8 — Audit et correctifs du mode hors-ligne

Lis d'abord `docs/agents/COORDINATION.md`.

## But
Savoir ce que fait chaque écran **sans réseau**, et corriger les trous qui
relèvent des services. L'application lit Data Dragon
(`ddragon.leagueoflegends.com`) via `DataDragonService.fetchJson(url,
{offlineKey})` et `OfflineJsonCache` (shared_preferences) ; les matchups sont un
fichier embarqué ; les images passent par `RemoteImage`.

## À faire
1. **Audit** : parcours `lib/**/services/*.dart`, `lib/data_dragon/**` et chaque
   page qui appelle un service. Pour chaque appel réseau, note : a-t-il un
   `offlineKey` ? que voit l'utilisateur en cas d'échec (message clair via
   `userMessageFor`, bouton « Réessayer » via `ErrorRetryView`, ou page blanche /
   spinner infini / exception non rattrapée) ? Écris le résultat dans
   **`docs/agents/reports/offline-audit.md`** : un tableau
   `service / appel / hors-ligne OK ? / problème / correctif`.
2. **Corrige** les trous qui sont dans des **services** et dans
   `lib/data_dragon/**` : ajouter le `offlineKey` manquant, rattraper une
   exception, éviter un spinner infini, délai maximal raisonnable si absent.
   Les **pages** (`*_page.dart`) et widgets ne sont pas à toi : pour chaque
   problème de page, écris-le dans le rapport (section « À traiter par
   l'architecte ») avec fichier et ligne ; ne l'édite pas.
3. **Tests** de chaque correctif, avec un faux client/chargeur qui échoue
   (regarde comment `DataDragonService` permet l'injection ; si ce n'est pas
   possible, ajoute le **plus petit** point d'injection, documenté) :
   `test/data_dragon/**`, `test/champions/**`, etc.
4. Vérifie que les **versions** (`16.19.1`) ne sont pas codées en dur au point
   de casser le hors-ligne : si le numéro de version vient du réseau, que se
   passe-t-il quand il est introuvable ?

## Fichiers qui t'appartiennent
`lib/data_dragon/**`, `lib/champions/services/**`, `lib/items/services/**`,
`lib/runes/**`, `lib/summoner_spells/**`, `lib/shared/errors/**`,
`docs/agents/reports/offline-audit.md`, et les tests correspondants. **Pas** les
pages ni les widgets.

## Définition de « fini »
Rapport écrit, correctifs testés, analyse propre sur tes dossiers, message au
journal résumant les points à traiter dans les pages.
