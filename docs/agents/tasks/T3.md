# T3 — Note « d'où viennent les données » partout

Lis d'abord `docs/agents/COORDINATION.md`.

## But
Les contre-picks, points forts, duels et bilans de draft reposent sur
`assets/data/champion_matchups.json` (Master+ EUW, plusieurs patchs). Aujourd'hui
chaque écran écrit sa propre phrase (`counters_page.dart` ligne ~198,
`strengths_page.dart` ligne ~212 : « Parties classées Master+ du patch X, … »).
Il faut **un seul composant** qui dit toujours la même chose, vraie, et l'afficher
partout où les chiffres apparaissent.

## À lire
`lib/matchups/models/matchup.dart` (`MatchupDataset` : `patch`, `matches`,
`matchups`, `MatchupDataset.empty()`), `lib/counters/counters_page.dart`,
`lib/strengths/strengths_page.dart`, `lib/champion_detail/widgets/matchup_section/`,
`lib/compare/widgets/head_to_head_card/`, `assets/data/champion_matchups.json`
(en-tête : `patch`, `matches`, `generatedAt`, `rank`, `platform`).

## À faire
1. Widget **`lib/shared/widgets/data_source_note/data_source_note.dart`** :
   `DataSourceNote({required MatchupDataset dataset})`. Texte du type
   « Données : 7 600 parties classées Master+ (EUW), patchs 16.16–16.19. »
   - espace insécable fine ou point pour séparer les milliers (`7 600`) ;
   - pas de « patch » au pluriel si un seul patch (`16.19`) ;
   - dataset vide (`matches == 0` ou `patch == null`) : « Aucune donnée de
     matchups disponible. » ;
   - style discret (`AppTheme.serif`, `AppColors.textMuted`), **sémantique** =
     le texte entier ; sans couleur codée en dur.
   Si `MatchupDataset` n'expose pas ce qu'il faut (nombre de parties, patch),
   ajoute-le **dans le modèle** sans casser son JSON. Un champ `generatedAt` ou
   `patches` peut exister dans le fichier : ne l'exige pas.
2. L'afficher à la place des phrases maison dans **`counters_page.dart`** et
   **`strengths_page.dart`** (T1 a libéré la seconde ; garde le reste des notes de
   bas de page sur la fiabilité « peu de données »), dans la section matchups de la
   **fiche champion** (`lib/champion_detail/widgets/matchup_section/`) et sous le
   **duel** du comparateur (`lib/compare/widgets/head_to_head_card/`).
3. Ne touche **pas** à `lib/draft/**` : T9b affichera la note dans la page de
   draft. Écris-lui le nom exact du widget au journal quand il est prêt.
4. Tests : `test/shared/widgets/data_source_note_test.dart` (texte normal,
   un seul patch, plage de patchs, milliers, dataset vide, sémantique) ; si les
   pages ont déjà des tests d'écran, complète-les ; sinon n'en crée pas
   (T14 s'en charge).
