# T15 — Page de la carte : « Réessayer » hors ligne

Lis d'abord `docs/agents/COORDINATION.md`. Rapport source :
`docs/agents/reports/offline-audit.md`, section « À traiter par l'architecte ».

## Problème
`lib/map/map_page.dart` (~l.178-180) : un `FutureBuilder` sur
`latestVersion()` affiche `MapPlaceholder('Chargement impossible')` quand la
version de Data Dragon est introuvable (hors ligne), **sans bouton « Réessayer »**,
et le futur (`late final _version`) n'est jamais relancé : l'utilisateur doit
quitter la page pour retenter. Toutes les autres pages passent par
`userMessageFor` et `ErrorRetryView`.

## À faire
1. Remplace ce cas par `ErrorRetryView(message: userMessageFor(error), onRetry: …)`
   (voir comment `lib/counters/counters_page.dart` ou `lib/team/team_page.dart` le
   font) ; « Réessayer » **recrée le futur** et reconstruit l'écran.
2. Garde le reste de la page identique (carte, calibration, marqueurs).
3. Test d'écran `test/map/map_page_retry_test.dart` : échec → message + bouton ;
   toucher « Réessayer » relance le chargement ; succès au second essai affiche
   la carte. Rends la source de la version **injectable** (paramètre du
   constructeur avec la valeur par défaut actuelle) pour pouvoir tester sans
   réseau. Pas de `pumpAndSettle` (voir COORDINATION §3 : les images bouclent).
4. Ne touche à rien d'autre : les autres lignes du rapport sont des sections
   « bonus » volontairement silencieuses.

## Fichiers qui t'appartiennent
`lib/map/**`, `test/map/**`.

## Définition de « fini »
Analyse propre sur `lib/map test/map`, tests passants, message au journal.
