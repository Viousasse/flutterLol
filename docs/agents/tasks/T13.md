   code sans la clé. Le préfixe `LOLD1.` ne change pas.
2. **Brouillon importé** : ajoute `final bool imported` (défaut `false`) à
   `DraftRecord` (constructeur, `from`, `toJson`/`tryFromJson`, absent =
   `false`). `DraftShareCode.decode` renvoie un enregistrement `imported: true`
   (c'est la draft de quelqu'un d'autre : contre le site, « le joueur » n'est pas
   vous). Dans `DraftHistoryStats`, une draft importée **ne compte pas** dans le
   taux de victoire ni dans `againstSite` ; elle compte dans `total` et dans les
   champions les plus choisis. La tuile d'historique (`DraftHistoryTile`) affiche
   une étiquette « IMPORTÉE » à côté de « AVEC AIDE » ; la carte de bilan dit
   « dont N importées (non comptées dans le taux) » quand il y en a. Tu es
   maintenant propriétaire de `draft_record.dart`, `draft_history_stats.dart`,
   `draft_history_tile.dart`, `draft_stats_card.dart`, `draft_history_page.dart`
   (T10 a fini) ; garde ses tests au vert et complète-les.
3. **Boîte de dialogue générique** `lib/shared/widgets/paste_code_dialog/paste_code_dialog.dart` :
   `PasteCodeDialog.show<T>(context, {required String title, required String hint,
   required T? Function(String text) parse, required String invalidMessage})` →
   `Future<T?>`. Champ multiligne, bouton « Coller » (lit le presse-papiers via
   `Clipboard.getData`, échec silencieux), « Importer » : appelle `parse` ; si
   `null`, **garde la boîte ouverte** et affiche `invalidMessage` sous le champ ;
   sinon renvoie le résultat. « Annuler » renvoie `null`. Focus automatique,
   libellés sémantiques.
4. **Builds** : dans `lib/builds/builds_page.dart` (tu en as le verrou jusqu'à
   ce que tu le libères, T14 le prend ensuite), une action d'AppBar « Importer

   `BuildShareCode.decode`, enregistre avec `BuildStore.save`, affiche une
   `SnackBar` « Build « X » importée » et la liste se met à jour toute seule

   de la liste affichée (comportement existant).
5. **Drafts** : dans `lib/draft/draft_history_page.dart`, une action d'AppBar
